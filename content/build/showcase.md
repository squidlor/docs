The showcase is the public list of what people have built on Squidlor. Browse it at [build.squidlor.com/showcase](https://build.squidlor.com).

## Get listed

1. Create a project in the [portal](https://build.squidlor.com) — name, description, category, links, logo.
2. Add media (optional): up to 6 screenshots and one demo video link. The first screenshot becomes your card's cover image.
3. Set its visibility to **listed**.
4. We review it.

Only reviewed entries appear publicly. An unreviewed submission could otherwise put arbitrary text and links on a Squidlor page, so the queue is not optional. Reviews happen weekly.

A verified listing earns 2,500 points in [Season 0](/build/rewards).

## What we look for

- The project exists and works.
- The description describes it accurately.
- It actually uses Squidlor — API traffic on your key, or a registered consumer contract.
- Nothing misleading about your relationship to us.

We are not judging quality or scale. A weekend dashboard qualifies; a landing page for something unbuilt does not.

## "Built with" tags

Each entry's tags are derived from **what your key actually consumed** over the last 30 days, not from what the submission form claimed. A project tagged `ohlc, history` really did pull candles and history.

Registered consumer contracts appear on the entry too, once verified.

## Editing a listing

You can edit any time. Changing the public-facing fields — name, description, links, logo, screenshots, demo video — returns the entry to the review queue, because a verified badge granted for one description should not silently transfer to another.

Category, chains and internal settings can be changed without re-review.

## Categories

`agent` · `defi` · `analytics` · `resolver` · `bot` · `other`

Pick the one a visitor would use to find you.

## Removal

Set visibility back to private and the entry disappears immediately. We also remove entries that break, become misleading, or stop using Squidlor entirely — we will email first.
